# スマート買い物（smart-shopping）

家族向けの「買い物最適化」アプリ（MVP）。単なる最安値検索ではなく、今日の買い物リスト全体について、どの店舗を何店舗回るのが最も合理的かを計算します。

このリポジトリは既存プロジェクト（Nexusほか）とは完全に独立しています。コード・データ・デプロイ設定を共有しません。

## 主な機能（MVP）

- チェーン／実店舗（支店単位）の管理
- カテゴリー／具体商品の管理（容量・比較単位つき）
- 税率マスター（taxCategories / taxRates）に基づく税込・税抜価格の自動計算
  - 商品には税率そのものではなく「税区分」を持たせ、価格確認日時点で有効な税率をマスターから取得
  - 価格レコードは確認日時点の税区分・適用税率・税込／税抜価格をスナップショットとして保存し、後から税率マスターを変更しても過去履歴は変わらない
  - 消費税の端数処理方式（切り捨て／四捨五入／切り上げ）を設定可能
- 商品ごとの価格履歴・価格分析（現在価格／過去最安値／平均価格／最高値）
- 容量違いを跨いだ単価比較（100mlあたり、100gあたり、1kgあたり、1個あたり等）
- 買い物リスト（商品指定・カテゴリー指定の両方に対応）
- 買い物最適化エンジン（1店舗／2店舗／店舗数制限なしの3パターンを計算し、節約額と店舗数のバランスでおすすめを提案）
- 店舗別の買い物リストと購入チェック
- 「いつもの商品」のワンタップ追加
- バーコード（JAN）読み取り：登録済み商品はすぐ呼び出して価格登録、未登録商品は Open Food Facts から商品名・メーカー・容量を自動入力（価格は取得しない。見つからない商品は手入力）
- iPhone優先のモバイルUI、PWA対応（ホーム画面追加・オフライン基本対応）

## 技術構成

- React + TypeScript + Vite
- データ永続化: localStorage（`smart-shopping:` プレフィックス）。画面から直接呼ばず、`src/repositories` の repository 層経由でアクセスするため、将来 Supabase 等へ差し替え可能な構造。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run test     # 税率エンジン・買い物最適化エンジンのロジックテスト
npm run lint     # oxlint
```
